Implementation guardrails
  • Use the actual existing design tokens and assets; these images do not define new colors or icon families.
  • Retain the icon-only Dashboard / Expenses / Add / Settlements / More navigation and all existing route/permission rules.
  • Keep every field, summary, confirmation, receipt state and analytics module, including content beyond the visible image.
  • Keep all twelve categories in one internally scrolling strip; do not copy the wrapped row in the Edit illustration.
  • Charts show the selected calendar month. Any illustration saying last 31 days is not the product rule.
  • Generated OS status-bar symbols are not part of the web UI. Fields, authoritative identity, data and exact attribution remain source-controlled.
  • See the full version 2 contract for remaining illustration differences and desktop acceptance gates.
