# AIDOS Project Control Center

This directory is the source of truth for AI-assisted work on House Finance Tracker.

- `PROJECT_RULES.md` — non-negotiable engineering and collaboration rules.
- `PROJECT_STATE.md` — current stage, decisions, gates, and known blockers.
- `REQUIREMENTS.md` — confirmed constraints plus the pending frozen product/design context.
- `IMPLEMENTATION_WORKFLOW.md` — phase, reasoning-level, and verification workflow.
- `AI_LESSONS.md` — durable lessons and corrections.
- `work/ACTIVE_PLAN.md` — the current plan; no feature work starts while its context gate is open.

The product requirements and UI/UX design are stated to be frozen, but their approved source context has not yet been provided in this workspace. That context is required before an implementation plan is created.
