- `PROJECT_STATE.md` — current stage, decisions, gates, and known blockers.
- `REQUIREMENTS.md` — the approved frozen product/design rules and dated amendments.
- `IMPLEMENTATION_WORKFLOW.md` — phase, reasoning-level, and verification workflow.
- `AI_LESSONS.md` — durable lessons and corrections.
- `work/ACTIVE_PLAN.md` — the current owner-authorized phase and verification gates.
- `work/HISTORY_READ_BENCHMARK_2026-10-11.md` — reproducible synthetic read measurements, the request-local projection optimization, browser evidence and a separate overflow finding awaiting approval.
